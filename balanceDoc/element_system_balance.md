## 2. 속성별 난이도 분석

### 2.1. 난이도 계산 공식

```
실제 난이도 = (기본 HP × 속성 HP modifier × 종족 HP modifier) / (입력 효율 × 유효 시간)

유효 시간 = 기본 제한 시간 (30초) / time_scale

입력 효율:
- 키보드 공격: 1.0 / keyboard_resistance
- 마우스 공격: 1.0 / mouse_resistance
- 혼합 입력: 평균 효율
```

## 3. 등장 확률 분석

### 3.1. 속성별 실제 등장 확률 (Batch 1 기준)

**계산 공식:**
```
등장 확률 = (속성 가중치 × 해당 속성 몬스터 수) / (모든 몬스터 가중치 합)
```

**Batch 1 구성:**
- 13종 일반 몬스터 × 6속성 = 78개 몬스터
- 2종 보스 (Fire Dragon, Dark Knight)

| 속성 | 가중치 | 몬스터 수 | 총 가중치 | 등장 확률 | 희귀도 등급 |
|------|--------|----------|----------|----------|------------|
| Normal | 100 | 13 | 1,300 | **36.0%** | Common |
| Fire | 50 | 13 | 650 | **18.0%** | Uncommon |
| Ice | 50 | 13 | 650 | **18.0%** | Uncommon |
| Wind | 50 | 13 | 650 | **18.0%** | Uncommon |
| Holy | 10 | 13 | 130 | **3.6%** ⚠️ | Very Rare |
| Dark | 30 | 13 | 390 | **10.8%** | Rare |
| **합계** | - | **78** | **3,610** | **100%** | - |

### 3.2. 희귀도 체감 분석

**희귀도 등급 체계:**

| 등급 | 확률 범위 | 체감 | 적용 속성 | 기대 등장 간격 |
|------|----------|------|----------|----------------|
| Common | 25~40% | "항상 본다" | Normal | 3 스테이지당 1회 |
| Uncommon | 15~25% | "자주 본다" | Fire/Ice/Wind | 5~6 스테이지당 1회 |
| Rare | 8~15% | "가끔 본다" | Dark | 9~12 스테이지당 1회 |
| Very Rare | 3~8% | "희귀하다" | **Holy (현재)** | **28 스테이지당 1회** ⚠️ |
| Ultra Rare | 1~3% | "매우 희귀" | - | - |

**문제점:**
- Holy 3.6%는 "Ultra Rare" 수준에 가까움
- 종족 도감 완성을 위해서는 **특정 Holy 몬스터 (0.26%)** 를 찾아야 함 → 약 385 스테이지!
- 이는 플레이어 이탈을 유발할 수 있는 수준

### 3.3. 특정 몬스터 등장 확률

**예시: Holy 슬라임**

```
등장 확률 = (종족 가중치 / 전체 종족 가중치) × (속성 가중치 / 전체 속성 가중치)
= (100 / 1,300) × (10 / 290)
= 0.077 × 0.034
= 0.26%
```

**95% 확률로 만나려면:**
```
스테이지 수 = ln(0.05) / ln(1 - 0.0026) ≈ 1,150 스테이지
```

**이는 비현실적으로 많은 플레이 시간을 요구합니다.**

**파일:** `config/GameData.json`

**변경 전:**
```json
"element_weights": {
  "normal": 100,
  "fire": 50,
  "ice": 50,
  "wind": 50,
  "holy": 10,
  "dark": 30
}
```

**변경 후:**
```json
"element_weights": {
  "normal": 100,
  "fire": 50,
  "ice": 50,
  "wind": 50,
  "holy": 40,    // 10 → 40 (4배 증가)
```

**장점:**

**절차:**
```python
# Python 스크립트 작성
import random

def simulate_collection(weights, target_count=78):
    collected = set()
    stages = 0

    while len(collected) < target_count:
        monster = weighted_random(weights)
        collected.add(monster)
        stages += 1

    return stages

# 1000회 반복 시뮬레이션
results_before = [simulate_collection(old_weights) for _ in range(1000)]
results_after = [simulate_collection(new_weights) for _ in range(1000)]

# 통계 분석
print(f"평균: {mean(results_before)} → {mean(results_after)}")
print(f"중앙값: {median(results_before)} → {median(results_after)}")
print(f"95%: {percentile(results_before, 95)} → {percentile(results_after, 95)}")
```

**성공 기준:**
- 평균 완성 스테이지: < 600
- 95% 완성 스테이지: < 1,000
