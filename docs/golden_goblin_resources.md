## 1. 이미지 규격

| 항목 | 값 |
|------|------|
| 해상도 | 1024 x 1024 px |
| 배경색 (크로마키) | #00FF00 (순수 녹색) |
| 스타일 | 픽셀아트 (기존 배경과 동일) |
| 포맷 | PNG |
| 배치 경로 | `Assets/Images/Background/` |

녹색(#00FF00) 영역은 게임에서 투명 처리됩니다. 바닥/벽 등 실제 배경 요소만 그리고 나머지는 녹색으로 남겨주세요.

기존 배경 참조: `Assets/Images/Background/bg_floor_cave_v1.png` (하단 45%가 바닥, 상단 55%가 녹색 크로마키)

## 2. 등급 시스템 참조

| 등급 | 배수 범위 | 출현 확률 | 테두리 색상 | HP |
|------|----------|----------|------------|-----|
| Bronze | 2x ~ 19x | ~6.7% | #CD7F32 (구리) | 80~120 |
| Silver | 20x ~ 40x | ~24.9% | #C0C0C0 (은) | 100~150 |
| Gold | 41x ~ 65x | ~44.3% | #FFD700 (금) | 120~180 |
| Diamond | 66x ~ 85x | ~20.0% | #B9F2FF (다이아) | 150~220 |
| Legendary | 86x ~ 100x | ~4.1% | #FF0000 (붉은) | 180~280 |

**스프라이트**: 모든 등급에서 동일한 `monster_goldengoblin.png` 사용 (금색 피부, 금화 자루를 짊어진 부자 고블린). 등급 차이는 **배경 + 테두리 색상 + 이펙트**로 표현.

---

## 3. 핵심 컨셉

> **등급이 올라갈수록 보화가 점점 많아지는 공간**

Bronze는 동전 몇 개가 떨어진 쓸쓸한 공간, Legendary는 보물이 넘쳐흐르는 금고.
같은 "보물 방" 테마이되, **밀도와 화려함의 차이**로 등급을 표현합니다.

## 4. 등급별 배경 상세

### 4.1 Bronze (청동)

| 항목 | 내용 |
|------|------|
| **파일명** | `bg_treasure_bronze.png` |
| **컨셉** | 어두운 돌바닥에 동전이 몇 개 흩어진 공간 |
| **색감** | 어둡고 차가운 회색/갈색 톤 |
| **바닥** | 어두운 돌/암석 바닥 (크랙 있어도 좋음) |
| **보화 요소** | 동전 5~8개 (구리/금 섞어서) 바닥에 흩어짐 |
| **소품** | 작은 돌맹이, 먼지 느낌 |
| **밀도** | ★☆☆☆☆ |

### 4.2 Silver (은빛)

| 항목 | 내용 |
|------|------|
| **파일명** | `bg_treasure_silver.png` |
| **컨셉** | 돌바닥에 동전 더미와 작은 보물상자가 있는 공간 |
| **색감** | 회색~은빛 톤, Bronze보다 약간 밝음 |
| **바닥** | 회색 돌바닥 (정돈된 느낌) |
| **보화 요소** | 동전 더미 2~3개, 흩어진 동전 10개+, 은화/금화 혼합 |
| **소품** | 나무 보물상자 1개 (닫힌 상태) |
| **밀도** | ★★☆☆☆ |

### 4.3 Gold (황금)

| 항목 | 내용 |
|------|------|
| **파일명** | `bg_treasure_gold.png` |
| **컨셉** | 금화 더미와 보물상자가 여러 개 있는 보물 방 |
| **색감** | 따뜻한 금빛/갈색 톤, 바닥에도 금빛 반사 |
| **바닥** | 돌바닥 + 금빛 어우러짐 |
| **보화 요소** | 금화 더미 3~4개 (중형), 흩어진 금화 20개+ |
| **소품** | 보물상자 2~3개 (금장식 포함), 반짝임 약간 |
| **밀도** | ★★★☆☆ |

### 4.4 Diamond (다이아몬드)

| 항목 | 내용 |
|------|------|
| **파일명** | `bg_treasure_diamond.png` |
| **컨셉** | 보석과 금이 가득한 호화로운 보물 창고 |
| **색감** | 푸른빛/보라빛 고급스러운 톤 + 금빛 |
| **바닥** | 장식된 돌바닥 (블루 틴트) |
| **보화 요소** | 대형 금더미 4개+, 보석(루비/사파이어/에메랄드) 다수, 금화 30개+ |
| **소품** | 금장 대형 보물상자 2~3개, 반짝임 효과 다수, 보석 크리스탈 |
| **밀도** | ★★★★☆ |

### 4.5 Legendary (전설)

| 항목 | 내용 |
|------|------|
| **파일명** | `bg_treasure_legendary.png` |
| **컨셉** | 보화가 넘쳐흐르는 전설적 보물 금고 |
| **색감** | 금빛이 지배적, 화려한 색상의 보석들 |
| **바닥** | 금빛 바닥 (바닥 자체가 금으로 덮임) |
| **보화 요소** | 거대한 금 산 6개+, 넘쳐나는 보물, 온갖 보석, 금화 50개+ |
| **소품** | 열린 보물상자 (금화 쏟아짐), 왕관, 반짝임 가득, 금장 대형 상자들 |
| **밀도** | ★★★★★ |

## 5. 등급 간 배경 차이 요약

```
Bronze    →  Silver    →  Gold      →  Diamond   →  Legendary
어두운       약간 밝은     따뜻한       고급스러운     금빛 폭발
동전 몇 개   동전더미+상자  금더미+상자들  보석+금더미    넘쳐나는 보화
★☆☆☆☆      ★★☆☆☆      ★★★☆☆      ★★★★☆       ★★★★★
```

## 6. 적용 방법

이미지가 준비되면 `config/SpecialMonsters.json`에서 `background` 경로만 변경. C# 코드 변경 없음.

```
bronze:    "Background/bg_floor_cave_v1.png"      → "Background/bg_treasure_bronze.png"
silver:    "Background/bg_floor_grassland_v2.png"  → "Background/bg_treasure_silver.png"
gold:      "Background/bg_floor_desert_v1.png"     → "Background/bg_treasure_gold.png"
diamond:   "Background/bg_floor_temple_v1.png"     → "Background/bg_treasure_diamond.png"
legendary: "Background/bg_floor_lava_v1.png"       → "Background/bg_treasure_legendary.png"
```
